# Python Practice

A collection of Python exercises completed while learning Python programming fundamentals.

## Topics Covered

- Lists and loops
- Dictionaries
- Functions
- String operations
- List comprehensions
- File handling
- Exception handling
- `*args` and `**kwargs`
- Modules
- Image pixel analysis

## How to Run

**Requirements:** Python 3

1. Clone the repository.
2. Open a terminal in the project folder.
3. Run an exercise using:

```bash
python3 01_even_numbers.py
```

Each exercise can be run independently. For the modules exercise, run `09_modules/main.py`.

## Purpose

To strengthen Python programming skills before moving on to NumPy, OpenCV, and computer vision projects.
